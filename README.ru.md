# niri-desk

Рабочий стол для niri: маленькие чёрные панели, номера рабочих столов, один остров сверху и цвета из обоев. Панель, лаунчер и дашборд написаны на Quickshell. Интерфейс доступен на английском и русском ([English](README.md)).

> Для установки CachyOS или Arch без рабочего стола. На Omarchy `install.sh` намеренно останавливается: конфликтуют настройки hypr, kitty и GTK.

## Установка

Установите CachyOS без рабочего стола, войдите в tty обычным пользователем и выполните:

```bash
sudo pacman -S --needed git
git clone https://github.com/voidsecurity404/niri-desk.git
cd niri-desk
./install.sh --dry-run   # показывает, что будет сделано, ничего не меняет
./install.sh
sudo reboot
```

Установщик добавляет пакеты, драйверы видеокарты (Intel и AMD), Claude Code, если он есть в ваших репозиториях, и включает NetworkManager, Bluetooth и звук. Он настраивает экран входа SDDM, если не включён другой display manager и не указан `--no-login-manager`. Если экран входа не запустился, нажмите `Ctrl+Alt+F2`, войдите и исправьте проблему оттуда. Драйверы NVIDIA не ставятся автоматически: на CachyOS выполните `sudo chwd -a`.

Текущие конфиги сохраняются в `~/.local/state/niri-desk/backup-*`. `./install.sh --uninstall` возвращает их, выключает SDDM и оставляет пакеты. Ваши клавиши из `user.kdl` сохраняются в `~/.local/state/niri-desk/user.kdl` и возвращаются при следующей установке.

## Язык

Настройки → Внешний вид → Язык: Авто, English или Русский. Авто следует системной локали. Перевод находится в `~/.config/niri-desk/i18n-ru.json`.

| `Mod+V` | История буфера |

| `Alt+Tab` | Последние окна с живым превью |

## Дашборд

Нажмите на часы. Две вкладки, переключаются клавишами `1`, `2` или `Tab`.

| Вкладка | Назначение |
| --- | --- |
| Сегодня | Время из живых частиц, которые разбегаются от указателя и дрожат при нагрузке на процессор, дата и погода, процессор, память, температура, диск и батарея, кнопка настроек |
| Музыка | Размытая, медленно движущаяся обложка на фоне, цвета из обложки, вращающаяся пластинка, перемотка по полосе времени и визуализатор, который следует за настоящим звуком. Звук только измеряется на этом компьютере |

## Виджеты рабочего стола

Часы, стрелочные часы, календарь, погода, нагрузка системы, музыка, лимиты Claude и заметки лежат на обоях. Чтобы их переместить, нажмите правой кнопкой по столу и выберите «Изменить виджеты» или нажмите `Mod+Shift+W`. В режиме правки виджет перетаскивается и прилипает к сетке, кнопка в углу меняет размер, крестик убирает, панель снизу добавляет новые. В настройках в разделе «Виджеты» их можно выключить, показать на всех столах и изменить прозрачность. Расположение хранится в `~/.config/niri-desk/widgets.json`.

## Лимиты Claude

Значок Claude стоит рядом с раскладкой. По нажатию видно расход за 5 часов и за неделю и время до сброса. Пока открыто это окно или виден виджет на столе, `niri-desk-claude-usage` каждые 10 секунд получает данные от Anthropic, используя вход Claude Code из `~/.claude/.credentials.json`, даже если Claude Code закрыт, а окно показывает обратный отсчёт до следующего запроса. Это недокументированный API, поэтому он может перестать работать; тогда окно покажет, насколько цифры устарели. Строка состояния Claude Code тоже сохраняет лимиты, пока он запущен. Один раз добавьте в `~/.claude/settings.json`:

```json
"statusLine": { "type": "command", "command": "~/.local/bin/niri-desk-claude-status", "refreshInterval": 5 }
```

## Вспомогательные команды

- `niri-desk-session save|restore`: восстановление окон. Сохраняется каждую минуту, восстанавливается при входе. Аргументы не повторяются, поэтому терминал откроется пустым.
- `niri-desk-backup export [файл]`, `import файл`: настройки в одном файле.
- `niri-desk-doctor`: проверяет программы, службы, конфигурацию и права и говорит, что исправить.
- `niri-desk-sync [--check] [--pull]`: копирует изменённые файлы из репозитория на рабочий стол, не трогая созданные файлы и данные пользователя.
- `niri-desk-login`: настраивает экран входа SDDM, просит sudo.
- Экран блокировки: Настройки → Система выбирает hyprlock или экран самой оболочки. `qs -c niri-desk ipc call desk lockPreview` показывает его без блокировки, Esc закрывает.
- `niri-desk-translate`: текст отправляется в онлайн-сервис перевода (`translate-shell`).

## Настройка

Почти всё меняется в окне `Mod+,` и применяется сразу: внешний вид, обои, панель, виджеты, окна, правила для приложений, мониторы, клавиатура, мышь и тачпад, горячие клавиши, терминал и система. Кнопка «Сбросить настройки» находится в разделе «Система». Если значение из этого окна отклонено, оно отменяется, а причина показывается на экране. Если вы правите `settings.json` вручную, файл не меняется, и настройки не применяются, пока вы не исправите значение, указанное в ошибке. Из командной строки: `niri-desk-set windows.gaps 8`.

| Что | Где |
| --- | --- |
| Все настройки | `~/.config/niri-desk/settings.json` |
| Свои привязки клавиш | `~/.config/niri/cfg/user.kdl` |
| Дополнительные настройки анимации | `~/.config/niri/cfg/layout.kdl` |
| Обои | `~/Pictures/Wallpapers`, видео для вкладки живых обоев в папке `Live`. Папку можно сменить в настройках |
| Скриншоты | `Screenshots` в папке изображений (`xdg-user-dir PICTURES`) |

## Статус

`tests/run.py` прогоняет сценарии на CachyOS в VirtualBox. Он закрывает окна и меняет настройки, поэтому запускайте его только на тестовой машине.

Ещё не проверено: автовосстановление окон при входе, второй монитор, яркость, предупреждения батареи, Wi-Fi, Bluetooth, тачпад, скорость на настоящей видеокарте, демонстрация экрана, вход с экрана входа и последний шаг кнопок выхода, перезагрузки и выключения.
