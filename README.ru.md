# niri-desk

Рабочий стол для niri: маленькие чёрные панели, номера рабочих столов, один остров сверху и цвета из обоев. Панель, лаунчер и дашборд написаны на Quickshell. Интерфейс доступен на английском и русском ([English](README.md)).

> Для установки CachyOS или Arch без рабочего стола. На Omarchy `install.sh` намеренно останавливается: конфликтуют настройки hypr, kitty и GTK.

## Установка

Установите CachyOS без рабочего стола, войдите в tty обычным пользователем и выполните:

```bash
sudo pacman -S --needed git
git clone https://github.com/voidsecurity404/niri-desk.git
cd niri-desk
./install.sh --dry-run   # показывает, что будет сделано, ничего не меняет
./install.sh
sudo reboot
```

Установщик добавляет пакеты, драйверы видеокарты (Intel и AMD), Claude Code, если он есть в ваших репозиториях, и включает NetworkManager, Bluetooth и звук. Он настраивает экран входа greetd, если не включён другой display manager и не указан `--no-login-manager`. Если экран входа не запустился, нажмите `Ctrl+Alt+F2`, войдите и исправьте проблему оттуда. Драйверы NVIDIA не ставятся автоматически: на CachyOS выполните `sudo chwd -a`.

Текущие конфиги сохраняются в `~/.local/state/niri-desk/backup-*`. `./install.sh --uninstall` возвращает их, выключает greetd и оставляет пакеты. Ваши клавиши из `user.kdl` сохраняются в `~/.local/state/niri-desk/user.kdl` и возвращаются при следующей установке.

Для ИИ-чата один раз войдите командой `claude auth login`.

## Язык

Настройки → Внешний вид → Язык: Авто, English или Русский. Авто следует системной локали. Перевод находится в `~/.config/niri-desk/i18n-ru.json`.

## Поиск

| Что ввести | Результат |
| --- | --- |
| `kit` | Приложения, открытые окна, буфер и действия |
| `2+2*3` или `=2^10` | Калькулятор, Enter копирует результат |
| `>nmap -sV 10.10.11.42` | Запускает команду в терминале |
| `?sql injection` | Поиск в интернете |
| `b64 текст`, `b64d`, `url`, `urld`, `hex`, `hexd`, `md5`, `sha256`, `html`, `htmld` | Кодирует или декодирует, Enter копирует |
| `jwt токен` | Показывает заголовок и данные JWT, подпись не проверяет |
| `hashid хеш` | Определяет тип хеша по длине и виду |
| `/пароль` | Ищет файлы в домашней папке, без скрытых |
| `;rev` | Сниппет: подставляет `{target}`, `{lhost}`, `{lport}` |
| `@pentest` | Открывает рабочий профиль |

Слова, набранные не в той раскладке, тоже находятся: `лшеен` → `kitty`.

## Дашборд

Нажмите на часы. Четыре вкладки, переключаются клавишами `1`–`4` или `Tab`.

| Вкладка | Назначение |
| --- | --- |
| Сегодня | Время, погода, таймер фокуса, календарь |
| Статус | Музыка, CPU, RAM, диск, батарея |
| Лаб | Цель, порты, VPN, быстрый скан, сбор доказательств, заметки по цели (`~/Pentest/<цель>/notes.md`) |
| ИИ | Чат с Claude |

## ИИ-чат

С подпиской Claude чат работает через Claude Code: установите его и войдите командой `claude auth login`, ключ API не нужен. Запросы расходуют лимиты подписки вместе с остальной работой в Claude Code. Чат работает без инструментов, поэтому не может читать файлы и выполнять команды.

Чтобы использовать ключ API, выберите его в Настройки → ИИ → Подключение и введите ключ. Он записывается в `~/.config/niri-desk/secrets/anthropic-key`, доступен только вам и не попадает в резервные копии, а запросы идут через официальный SDK `anthropic` из `~/.local/share/niri-desk/venv`. Использование API оплачивается отдельно. В режиме Авто используется Claude Code, если найдена команда `claude`.

Модель по умолчанию `claude-opus-5-5`, другую можно выбрать в настройках. Сообщения и IP текущей цели отправляются в Anthropic. Переписка хранится в `~/.local/state/niri-desk/ai-history.json`.

## Списки в файлах

`~/.config/niri-desk/profiles.json`: рабочие профили. Номера `workspace` задают порядок: niri не хранит пустые столы, поэтому при пропуске номера окна встают подряд.

`~/.config/niri-desk/snippets.json`: сниппеты. `"run": true` запускает в терминале, иначе текст копируется. Если цель или IP пусты, ничего не запускается, текст только копируется.

## Вспомогательные команды

- `niri-desk-session save|restore`: восстановление окон. Сохраняется каждую минуту, восстанавливается при входе. Аргументы не повторяются, поэтому терминал откроется пустым.
- `niri-desk-backup export [файл]`, `import файл`: настройки, профили и сниппеты в одном файле.
- `niri-desk-translate`: текст отправляется в онлайн-сервис перевода (`translate-shell`).

## Настройка

Почти всё меняется в окне `Mod+,` и применяется сразу: внешний вид, окна, правила для приложений, панель, клавиатура, горячие клавиши, мониторы, ИИ и система. Если значение из этого окна отклонено, оно отменяется, а причина показывается на экране. Если вы правите `settings.json` вручную, файл не меняется, и настройки не применяются, пока вы не исправите значение, указанное в ошибке. Из командной строки: `niri-desk-set windows.gaps 8`.

| Что | Где |
| --- | --- |
| Все настройки | `~/.config/niri-desk/settings.json` |
| Свои привязки клавиш | `~/.config/niri/cfg/user.kdl` |
| Дополнительные настройки анимации | `~/.config/niri/cfg/layout.kdl` |
| Обои | `~/Pictures/Wallpapers` |

Если задать `vpn.up` и `vpn.down` в `settings.json`, заработает кнопка щита в центре управления. Например: `nmcli con up htb` и `nmcli con down htb`.

## Статус

`tests/run.py` прогоняет сценарии на CachyOS в VirtualBox, результаты в `tests/REPORT.md`. Он закрывает окна и меняет настройки, поэтому запускайте его только на тестовой машине.

Ещё не проверено: ИИ-чат с настоящим ключом API (путь через Claude Code проверен с настоящей подпиской), автовосстановление окон при входе, второй монитор, яркость, предупреждения батареи, Wi-Fi, Bluetooth, тачпад, скорость на настоящей видеокарте, демонстрация экрана, вход с экрана входа и последний шаг кнопок выхода, перезагрузки и выключения.
